# 信州みらい病院 重点投資を考える v7

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 体験の流れ

1. 「重点投資を考える」を最後まで見る
2. 第1回案を入力できるようになる
3. 「地域の高齢化と職員負担」を見る
4. 最終案を入力できるようになる
5. 「結果比較」で第1回案と最終案を比較する

同じブラウザでは、第1回案・最終案・視聴完了状態・シナリオ編集内容が保持されます。

## 入力仕様

- チーム名
- 呼び名
- 投資案1〜4
- 金額1〜4
- 最も重視した視点

投資案と金額：

- A：MRI更新 = 70万円
- B：看護師採用 = 10 / 20 / 30万円
- C：小児科強化 = 30万円
- D：病院DX = 30 / 40 / 50 / 60万円
- E：健診事業強化 = 10 / 20 / 30万円

同じ投資案の重複選択はできません。合計100万円を超える選択肢は自動的に選択不可になります。

## 結果比較

結果比較画面では以下を表示します。

- 回答者数
- チーム数
- 第1回案数
- 最終案数
- A〜Eごとの第1回案／最終案の平均配分
- チーム名・呼び名ごとの第1回案／最終案比較
- 最も重視した視点の比較
- チーム名、呼び名による絞り込み

## 複数人で共有する場合

共有DBを設定しない場合、入力データは各ブラウザ内だけに保存されます。
複数端末の結果を1つのBI画面で比較する場合は Supabase を設定します。

1. Supabaseでプロジェクトを作成
2. SQL Editorで `supabase_setup.sql` を実行
3. Streamlit Community Cloud の App settings → Secrets に以下を登録

```toml
SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY"
```

設定後は、入力内容が共有DBへ保存され、「結果比較」で複数端末の回答をまとめて表示します。
