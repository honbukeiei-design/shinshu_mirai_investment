# 信州みらい病院 重点投資 Streamlit v5

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Community Cloud では Main file path に `app.py` を指定してください。

## 操作

- `次へ`：シナリオを進行
- `場面`：導入、投資案A〜E、まとめの開始位置へ移動
- `編集`：現在の画面に応じた編集画面を表示

## 編集できる項目

会話画面では、シナリオ本文、話者、話者表示名、本文文字サイズ、話者名文字サイズ、背景、BGMを編集できます。
タイトル画面では、タイトル、サブタイトル、リード文と各文字サイズを編集できます。
場面転換画面では、場面タイトル、場面タイトル文字サイズ、BGMを編集できます。

## 編集内容の保存

`反映して保存` を押した編集内容はブラウザの localStorage に自動保存されます。
そのため、通常の再読み込み、Ctrl + F5、ブラウザ再起動後も同じブラウザでは編集内容が維持されます。

## GitHub上の本体へ反映する方法

編集画面の `設定を書き出す` を押すと `saved_edits.json` がダウンロードされます。
このファイルをGitHubリポジトリの `app.py` と同じ階層にある `saved_edits.json` と置き換えてコミットしてください。
以後、その内容がアプリの共通初期設定として読み込まれます。

ブラウザ固有の編集内容が残っている場合は、そちらがGitHub上の `saved_edits.json` より優先されます。共通初期設定を確認したい場合は編集画面の `編集をリセット` を使用してください。
