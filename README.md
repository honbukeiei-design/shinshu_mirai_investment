# 信州みらい病院 重点投資を考える

## Streamlit Community Cloud

- Main file path: `app.py`
- Python: Streamlit Community Cloud の標準環境で動作

## 体験の流れ

1. 初回は「重点投資を考える」本編を開始します。
2. 本編終了後、「地域の高齢化と職員負担」へ進めます。
3. 本編を一度完了したブラウザでは、初期画面から両方を選べます。

## 編集

画面左上の「編集」から、本文、話者、話者名、文字サイズ、背景、BGM、場面タイトル等を編集できます。編集内容はブラウザの localStorage に保存されます。

「設定を書き出す」で `saved_edits.json` を保存し、GitHub リポジトリの同名ファイルと置き換えると、編集内容を標準設定として配布できます。
